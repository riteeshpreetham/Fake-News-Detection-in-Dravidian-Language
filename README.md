# Fake-News-Detection-in-Dravidian-Language
GitHub README Introduction

Fake News Detection in Dravidian Languages is a deep learning-based Natural Language Processing (NLP) project designed to combat misinformation in low-resource Indian languages. The model combines MuRiL embeddings, Residual CNN (ResNet), and Bidirectional LSTM (BiLSTM) to capture contextual and sequential linguistic features, enabling accurate classification of news articles as Fake or Real. The system supports Telugu, Tamil, Kannada, and Malayalam, addressing the unique challenges of multilingual fake news detection.

Repository Highlights
🧠 MuRiL Transformer for multilingual contextual embeddings
🔍 Residual CNN (ResNet) for local feature extraction
🔄 Bidirectional LSTM (BiLSTM) for sequence learning
🌐 Supports Telugu, Tamil, Kannada, and Malayalam
📊 Achieved over 92% classification accuracy on the Dravidian_Fake dataset
🚀 Built using Python and modern deep learning frameworks
